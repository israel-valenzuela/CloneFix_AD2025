# Introduccion

El proyecto CloneFli es una aplicación web inspirada en plataformas de streaming populares, 
cuyo objetivo principal es permitir a los usuarios explorar, buscar y visualizar información 
sobre series y películas de forma sencilla e interactiva. A través de una interfaz moderna y 
dinámica, se conecta con la API pública de TVmaze para obtener datos en tiempo real.

---

## Descripcion

La aplicación está construida con una base sólida en HTML5, estilos personalizados en CSS y funcionalidades dinámicas con JavaScript.

- Interfaz de navegación: un menú superior que incluye la marca del sitio y un buscador para localizar títulos específicos.
- Filas de contenido: despliegan miniaturas organizadas en carruseles horizontales para explorar diferentes categorías, como “Tendencias”.
- Modal de detalles: al seleccionar un título, se abre una ventana con más información sin recargar la página.

---

## Funcionalidades

La primera versión hace uso de Bootstrap para un diseño responsivo y moderno, complementado con estilos propios para personalizar la apariencia tipo “plataforma de streaming”. El código JavaScript realiza peticiones fetch a la API para mostrar contenido dinámico en la página
